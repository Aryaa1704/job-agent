# 🤖 AI Job Agent — India Edition

Personal AI-powered job application assistant built for Indian job market.

## Features
- 🇮🇳 **India Job Scraper** — Internshala, Foundit, Naukri, Wellfound, Remotive
- 🎯 **Industry ATS Checker** — 10-parameter scoring (Harvard OCS criteria)
- 📄 **ATS Resume Builder** — JD-tailored resume with keyword optimization
- 🚀 **Smart Apply Assistant** — Cover letter + Form data + Direct apply links
- 📊 **Application Tracker** — Track applied/interview/offer status

## Tech Stack
Python · FastAPI · Streamlit · Groq (LLaMA 3.3 70B) · BeautifulSoup · REST APIs

## Setup
```bash
pip install -r requirements.txt
export GROQ_API_KEY="your_key"
streamlit run dashboard/app.py
```
